# Aura

Aura is a Flutter-based mobile application designed to deliver a secure, AI-assisted medical chat experience. It combines Firebase authentication and cloud persistence with an AI backend routed through an `n8n` workflow to power health symptom conversations and care guidance.

## Overview

Aura enables authenticated users to:
- Sign in and sign up securely with Firebase
- Maintain multiple medical chat conversations
- Persist message history in Firestore per user
- Send symptoms or health questions to an AI workflow
- Receive AI-driven responses through `n8n`

## Cenario

This section describes a sample usage scenario for Aura:
- A patient opens the app and logs in securely.
- They describe symptoms or ask a health-related question.
- The message is sent to the AI workflow through `n8n`.
- The app saves the conversation to Firestore so the user can review it later.
- The patient receives an AI-guided response tailored to their inquiry.

## Features

- Firebase Authentication for login, signup, and session management
- Cloud Firestore storage for conversations and message history
- Conversation lifecycle management: create, list, delete
- AI message processing via `n8n` webhook integration
- Input validation for email, passwords, and chat messages
- Responsive Flutter UI designed for a clinical medical assistant app

## Architecture

- `lib/main.dart` — App entry point and Firebase initialization
- `lib/views/` — Screens for login, signup, chat, and setup flows
- `lib/viewmodel/` — Business logic and state management using `provider`
- `lib/services/` — Backend integration services for Firebase and AI
- `lib/models/` — Domain models such as `ChatConversation` and `Message`
- `lib/theme/` — Shared app styling and theme data

## AI Integration

Aura uses `n8n` as the AI orchestration layer. The app forwards chat messages to an `n8n` webhook and consumes the returned assistant response.

Key points:
- `lib/services/chat_service.dart` contains `ChatService.sendMessageToN8n()`
- Requests are sent as JSON to the configured `n8n` webhook URL
- The workflow can integrate with OpenAI, other LLM providers, or custom business logic
- The response payload is parsed for fields like `message`, `response`, or `data`

Example webhook placeholder in code:

```dart
static const String n8nWebhookUrl =
    'http://10.162.238.64:5678/webhook-test/chat';
```

> Update this URL to point to your production or development `n8n` endpoint.

## Firebase Integration

Aura relies on Firebase for authentication and chat persistence.

Required configuration:
- `android/app/google-services.json`
- `ios/Runner/GoogleService-Info.plist`
- `lib/firebase_options.dart` should be generated by the FlutterFire CLI

Firestore layout:
- `users/{userId}/conversations/{conversationId}`
- `users/{userId}/conversations/{conversationId}/messages/{messageId}`

## Setup and Run

1. Install Flutter: https://docs.flutter.dev/get-started/install
2. Install dependencies:

```bash
flutter pub get
```

3. Configure Firebase:
- Add `google-services.json` to `android/app`
- Add `GoogleService-Info.plist` to `ios/Runner`
- Confirm `lib/firebase_options.dart` matches your Firebase project

4. Run the app:

```bash
flutter run
```

## Notes

- After any Firebase configuration changes, perform a full restart of the app.
- If conversation UI issues appear, verify `ChatViewModel` is correctly provided in the widget tree.
